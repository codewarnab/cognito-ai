# Writing Style Standards

## Use Simple Words
| ❌ Don't | ✅ Do |
|----------|-------|
| utilize | use |
| facilitate | help |
| leverage | use |
| commence | start |
| terminate | stop |

## No Filler Words
| ❌ Before | ✅ After |
|-----------|---------|
| Please don't... | Don't... |
| You can configure... | Configure... |
| If it doesn't work, you may... | If it doesn't work, ... |
| Personally, I would recommend | Use... |

## Subject First
Place subject at beginning of sentences:
| ❌ Before | ✅ After |
|-----------|---------|
| One of the frameworks, Fumadocs... | Fumadocs is a framework... |
| You can configure C to enable B | To enable B, configure C |

## Paragraph Rules
- Max 10-12 words per line
- Max 9 lines per paragraph
- Give each paragraph a meaningful heading

## Lists and Tables
- Use bullet lists instead of complex English connectives
- Use tables for conditions and properties
- Use **bold** for skimming emphasis

## Headings
- More headings = better navigation
- Provide anchors for linking
- Help readers find information faster

## Hyperlinks
- Link relevant resources when mentioning names
- Example: [Fumadocs](https://fumadocs.vercel.app)

## Avoid Sequential Language
| ❌ Don't | ✅ Do |
|----------|-------|
| 1. Install... 2. Configure... | ### Install ### Configure |
| First... Then... | Install first. Configure next. |
