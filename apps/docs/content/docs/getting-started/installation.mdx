## Installation Options

You can install Cognito AI either through the Chrome Web Store or by building it from source.

### 1. Chrome Web Store (Recommended)

The easiest way to install Cognito AI is via the Chrome Web Store.

### 2. Install from Source

Building from source allows you to contribute to the project or use the latest development features.

#### Prerequisites

- Google Chrome browser (version 120+)
- Node.js 18+ and pnpm

#### Clone the Repository

```bash title="Terminal"
git clone https://github.com/codewarnab/cognito-ai.git
cd cognito-ai
```

### Configure Environment Variables

Before installing dependencies, you need to set up the environment variables.

#### 1. Extension Configuration

Create a `.env` file in `apps/extension/`:

```bash title="Terminal"
cp apps/extension/.env.example apps/extension/.env
```

Update the `apps/extension/.env` file with your configuration.

#### 2. Backend Configuration

<Callout type="warn">
  The **hosted backend services** (Vercel API + Cloudflare ElevenLabs proxy) are **closed-source** and are not included when building from source.

  When installing from source, use **BYOK (Bring Your Own Key) Mode** (or **Local Mode**, if available). You do not need backend environment variables unless you are building a **compatible backend implementation** (see [Backend Services](/docs/integrations/backends)).
</Callout>

### Configure BYOK Mode

To use the extension without the official backend:

1. Open the extension settings
2. Open **Providers**
3. Select your provider (Google, OpenAI, Anthropic, etc.)
4. Enter your **API Key**
5. Ensure **Cloud Mode** is disabled

The extension will perform AI generation locally or via direct API calls to your chosen provider.

#### 3. Webapp Configuration

Create a `.env` file in `apps/webapp/`:

```bash title="Terminal"
cp apps/webapp/.env.example apps/webapp/.env
```

You will need to update `NEXT_PUBLIC_EXTENSION_ID` with your local extension ID (found at `chrome://extensions`).

### Install Dependencies


```bash title="Terminal"
pnpm install
```

### Build the Extension

```bash title="Terminal"
pnpm build:extension
```

This creates the extension in `apps/extension/dist/chrome-mv3/`.

### Load in Chrome

1. Open `chrome://extensions`
2. Enable **Developer mode** (top-right toggle)
3. Click **Load unpacked**
4. Select the `apps/extension/dist/chrome-mv3` folder

## Verify Installation

| Check | Expected Result |
|-------|-----------------|
| **Toolbar icon** | Cognito AI icon appears in Chrome toolbar |
| **Side panel** | `Ctrl+Shift+H` (Windows) or `Cmd+Shift+H` (Mac) opens the panel |

<Callout title="Tip">
  Pin the extension to your toolbar for quick access. Find the **Cognito icon** in the extensions menu and pin it.
</Callout>

<Callout title="Shortcut not working?" type="warn">
  You can configure it at `chrome://extensions/shortcuts`.
</Callout>
