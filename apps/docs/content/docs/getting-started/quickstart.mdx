## What You'll Learn

- Opening the side panel

## Prerequisites

- Cognito AI [installed](/docs/getting-started/installation)
- AI provider [configured](/docs/getting-started/provider-setup) (or use Backend mode)

## Open the Side Panel

Use the keyboard shortcut:

| Platform | Shortcut |
|----------|----------|
| **Windows/Linux** | `Ctrl+Shift+H` |
| **Mac** | `Cmd+Shift+H` |

Or click the Cognito AI icon in your Chrome toolbar.

## Start a Conversation

Type a message and press **Enter**. The AI responds in the chat panel.

### Example Prompts

Try these to get started:

```text
Summarize this page
```

```text
What are the main topics discussed here?
```

```text
Find all links on this page
```

## Core Features

| Feature | Description |
|---------|-------------|
| **Page Context** | Ask questions about the current webpage |
| **Browser Automation** | Navigate, click, type, and extract data |
| **Attachments** | Attach screenshots or files to your message |
| **Memory** | Save and recall information across sessions |
| **Voice Mode** | Speak instead of typing |

> [!TIP]
> Click the **attachment** button to include a screenshot of the current page in your message.

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+Shift+H` | Open/close side panel |
| `Enter` | Send message |
| `Shift+Enter` | New line in message |
