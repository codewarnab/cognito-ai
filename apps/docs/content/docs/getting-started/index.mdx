**Cognito AI** is a privacy-first AI assistant built into your Chrome browser. The side panel provides chat, browser automation, voice mode, and web research capabilities.

- Installing the Chrome extension
- Configuring an AI provider (BYOK or Cloud mode)
- Opening the side panel and starting your first conversation
- (Optional) Connecting to CLI agents via the CLI Bridge

## CLI Bridge (Optional)

Cognito AI can connect to local CLI coding agents like **Gemini CLI**, **Claude Code**, and **Codex CLI** through the CLI Bridge. This enables you to use your existing CLI agent subscriptions directly from the browser.

The CLI Bridge is a lightweight local server that:
- Spawns local agent CLIs via ACP (Agent Communication Protocol)
- Streams responses back to the extension
- Manages code patches and applies them via `git apply`

See [Provider Setup](/docs/getting-started/provider-setup#cli-mode-experimental) for configuration details.
