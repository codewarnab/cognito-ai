**Cognito AI** is a privacy-first AI assistant built into your Chrome browser. The side panel provides chat, browser automation, voice mode, and web research capabilities.

## What You'll Learn

- Installing the Chrome extension
- Configuring an AI provider (BYOK or Backend mode)
- Opening the side panel and starting your first conversation
