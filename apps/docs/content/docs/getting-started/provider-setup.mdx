## What You'll Learn

- Choosing between **BYOK** (Bring Your Own Key) and **Cloud** mode
- Configuring your AI provider (Google, OpenAI, Anthropic, and more)
- Understanding rate limits and mode tradeoffs

## AI Provider Modes

Cognito AI supports two modes for AI processing:

| Mode | API Key Required | Best For |
|------|------------------|----------|
| **Cloud Mode** | No | Quick start, casual use |
| **BYOK Mode** | Yes | Privacy, no rate limits, multi-provider |

<Callout type="info">
In **BYOK Mode**, your API keys are stored locally and never sent to any server except the provider's API you choose.
</Callout>

## Configure Cloud Mode

Cloud mode requires no setup (in the official hosted version). Toggle it on and start chatting.

**Rate limits apply** — the shared backend has usage quotas. If limits are exceeded and you have an API key configured, Cognito automatically falls back to BYOK mode.

<Callout type="warn">
If you have built from source, **Cloud Mode will not work** because the hosted backend services are not included. You must use **BYOK Mode** with your own API key (or Local Mode, if available).
</Callout>

### Toggle Cloud Mode

1. Open the side panel (`Ctrl+Shift+H`)
2. Click the **settings gear** icon
3. Enable **Cloud Mode** (shown as “Cloud” in the toolbar)

### API Usage & Suggestion Actions

Whichever mode is selected in your chat input will consume API requests for **all features**, including **Suggestion Actions** (the contextual quick actions that appear above the chat input).

If you're not using Suggestion Actions or want to reduce costs, you can disable them in [Settings](https://cognito-ai-one.vercel.app/settings).

<Callout>
**Coming Soon:** Hybrid routing — mix Cloud and BYOK modes for different features. For example, use Cloud Mode for writing, rewriting, and summarization while using BYOK for chat, or use Cloud Mode only for suggestion generation.
</Callout>

## Configure BYOK Mode

BYOK mode connects directly to your chosen AI provider using your personal API key.

### Supported Providers

Cognito AI is **multi-provider** and supports the following AI providers:

| Provider | API Key Source |
|----------|----------------|
| **Google Gemini** | [Google AI Studio](https://aistudio.google.com/) |
| **OpenAI** | [OpenAI Platform](https://platform.openai.com/api-keys) |
| **Anthropic** | [Anthropic Console](https://console.anthropic.com/) |
| **Vertex AI** | [Google Cloud Console](https://console.cloud.google.com/) |
| **xAI (Grok)** | [xAI Console](https://x.ai/) |

### Enter Your API Key

1. Open the side panel
2. Open **Settings** → **Providers**
3. Select your preferred provider
4. Paste your API key

<Callout>
Cloud mode uses a fixed model (currently Gemini 2.5 Flash). BYOK mode lets you choose any model from your configured providers.
</Callout>
