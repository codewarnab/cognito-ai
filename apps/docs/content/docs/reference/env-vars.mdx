Complete reference for all environment variables used across Cognito AI packages.

## Extension (`apps/extension/`)

All extension variables are prefixed with `WXT_`.

### Backend URLs

| Variable | Description | Default |
|----------|-------------|---------|
| `WXT_ELEVENLABS_WORKER_URL` | ElevenLabs proxy URL | Cloudflare production |
| `WXT_BACKEND_API_URL` | Main backend API URL | Vercel production |
| `WXT_METADATA_API_URL` | Metadata extraction API | Vercel production |
| `WXT_TRANSCRIPT_API_URL` | YouTube transcript API | Vercel production |

### Webapp URLs

| Variable | Description | Default |
|----------|-------------|---------|
| `WXT_WEBAPP_URL_DEV` | Webapp URL for development | `http://localhost:3002` |
| `WXT_WEBAPP_URL_PROD` | Webapp URL for production | Vercel production |

### Feature Flags

| Variable | Description | Default |
|----------|-------------|---------|
| `WXT_HIDE_LOCAL_MODE` | Hide Chrome built-in AI option | `true` |
| `WXT_YOUTUBE_BADGE_PREFETCH` | Prefetch YouTube badges | `true` |

### Usage

```typescript title="apps/extension/src/example.ts"
// Always use the ENV module
import { ENV } from '@/utils/env';

const backendUrl = ENV.BACKEND_API_URL;
const isLocalHidden = ENV.HIDE_LOCAL_MODE;
```

## Backend Services (Reference Only)

<Callout type="warn">
  The backend packages are **not open-source**. These environment variables are documented for reference purposes only. You cannot contribute to backend code.
</Callout>

### Backend Cloudflare

### Secrets (via wrangler)

| Variable | Description | Required |
|----------|-------------|----------|
| `ELEVENLABS_API_KEY` | ElevenLabs API key | Yes |

Set via:
```bash title="Terminal"
wrangler secret put ELEVENLABS_API_KEY
```

### Variables (in wrangler.toml)

| Variable | Description | Required |
|----------|-------------|----------|
| `ELEVENLABS_AGENT_ID` | Voice agent ID | Yes |

Set in `wrangler.toml`:
```toml title="wrangler.toml"
[vars]
ELEVENLABS_AGENT_ID = "agent_xxx"
```

### Backend Vercel

### Required

| Variable | Description |
|----------|-------------|
| `GOOGLE_AI_API_KEY` | Google Gemini API key for AI endpoints |
| `SUPADATA_API_KEY` | Supadata API key for YouTube transcripts |

### Optional

| Variable | Description |
|----------|-------------|
| `TAVILY_API_KEY` | Tavily API key for web search |
| `JINA_API_KEY` | Jina API key for URL content extraction |
| `UPSTASH_REDIS_REST_URL` | Upstash Redis URL for rate limiting |
| `UPSTASH_REDIS_REST_TOKEN` | Upstash Redis token for rate limiting |

### Example `.env`

```bash title="packages/backend-vercel/.env"
# Required
GOOGLE_AI_API_KEY=your_gemini_key
SUPADATA_API_KEY=your_supadata_key

# Optional - Web search
TAVILY_API_KEY=your_tavily_key

# Optional - URL content extraction
JINA_API_KEY=your_jina_key

# Optional - Rate limiting
UPSTASH_REDIS_REST_URL=https://xxx.upstash.io
UPSTASH_REDIS_REST_TOKEN=your_token
```


## Environment Precedence

| Build | Source |
|-------|--------|
| Development | `.env` files |
| Production | Platform dashboard (Vercel, Cloudflare) |
| CI/CD | GitHub Secrets / environment |

## Troubleshooting

### Variable Not Available

**Symptoms**: `undefined` or empty value at runtime

<Callout>
  **Checklist:**
  - Restart the dev server after changing `.env`
  - Verify the variable is prefixed correctly (`WXT_` for extension)
  - Use the `ENV` module, not `import.meta.env`
</Callout>

### Wrong Environment

**Symptoms**: Calling production API in development

<Callout>
  Verify the `.env` file is loaded and contains correct values.
</Callout>
