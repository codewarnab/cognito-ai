## Prerequisites

| Requirement | Version | Notes |
|-------------|---------|-------|
| **Node.js** | 18+ | LTS recommended. Run `node -v` to check |
| **pnpm** | 8+ | Installed via corepack |
| **Git** | 2.0+ | For version control |
| **Chrome** | 120+ | For extension testing |

## Installation

### Clone the Repository

Fork the repository on GitHub first, then clone:

```bash title="Terminal"
git clone https://github.com/YOUR_USERNAME/cognito-ai.git
cd cognito-ai
```

### Enable Corepack

Corepack manages the package manager version:

```bash title="Terminal"
corepack enable
```

### Install Dependencies

Install dependencies for all packages in the monorepo:

```bash title="Terminal"
pnpm install
```

## Environment Configuration

### Extension Environment

Copy the example environment file:

```bash title="Terminal"
cp apps/extension/.env.example apps/extension/.env
```

Common development variables:

```bash title="apps/extension/.env"
# Point to local backend (optional)
WXT_BACKEND_API_URL=http://localhost:3001
WXT_WEBAPP_URL_DEV=http://localhost:3002

# Feature flags
WXT_HIDE_LOCAL_MODE=false
```

## Development Servers

### Extension Only

Start the WXT dev server with hot reload:

```bash title="Terminal"
pnpm dev
```

### All Packages

Run everything in parallel:

```bash title="Terminal"
pnpm dev:all
```

This starts:
- **Extension** — port 8080
- **Webapp** — port 3002
- **Backend** — port 3001
- **Docs** — port 3000

### Specific Packages

```bash title="Terminal"
pnpm dev               # Extension
pnpm dev:docs          # Documentation
pnpm dev:webapp        # Webapp

# Using filter:
pnpm --filter @cognito/extension dev
pnpm --filter @cognito/docs dev
```

## Loading the Extension

### Development Build

Run the dev server, then load the extension in Chrome:

```bash title="Terminal"
pnpm dev
```

In Chrome:
- Navigate to `chrome://extensions`
- Enable **Developer mode** (toggle in top right)
- Click **Load unpacked**
- Select the `dist` directory

### Production Build

Build and load the extension:

```bash title="Terminal"
pnpm build:extension
```

Load `dist` as above.

### Verify Installation

- Click the Cognito icon in the toolbar
- Or use keyboard shortcut: `Ctrl+Shift+H` (Mac: `Cmd+Shift+H`)
- The side panel should open

## Hot Reload

WXT provides hot reload for most changes:

| Change Type | Behavior |
|-------------|----------|
| **React components** | Auto-refresh |
| **CSS** | Auto-refresh |
| **Background script** | Manual extension reload required |
| **Manifest changes** | Manual extension reload required |

<Callout>
  To manually reload: go to `chrome://extensions` and click the reload button on Cognito.
</Callout>

## Troubleshooting

### pnpm: command not found

Enable corepack:

```bash title="Terminal"
corepack enable
```

### Dependency Installation Fails

Clear pnpm cache and reinstall:

```bash title="Terminal"
pnpm store prune
rm -rf node_modules
pnpm install
```

### Extension Won't Load

Check these common issues:
- **Developer mode** — Must be enabled in Chrome
- **Build status** — Ensure the build completed without errors
- **Directory** — Select `dist`, not the project root

### Hot Reload Not Working

Try these solutions:
- Manually reload the extension
- Restart the dev server
- Check for build errors in the terminal

### Port Already in Use

Kill the process and restart:

```bash title="Terminal"
# Find process on port 3000 (example)
lsof -i :3000
kill -9 <PID>
```

Or use a different port:

```bash title="Terminal"
PORT=3001 pnpm dev
```
