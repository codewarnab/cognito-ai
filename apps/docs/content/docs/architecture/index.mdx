## Technology Stack

| Layer | Technology |
|-------|------------|
| **Extension** | WXT + React 19 + TypeScript |
| **State** | Zustand + Chrome Storage |
| **Styling** | TailwindCSS + shadcn/ui |
| **AI SDK** | Vercel AI SDK v6 |
| **Backend** | Express (Vercel) + Hono (Cloudflare) |
| **Database** | IndexedDB (Dexie) |
| **Package Manager** | pnpm (monorepo) |

## Key Design Decisions

### Privacy-First

All user data stays on the device. The extension uses:
- Chrome `storage.local` for preferences
- IndexedDB for messages and threads
- No analytics or telemetry

### Multi-Provider Support

The AI system supports multiple configurations:
- Local (Chrome built-in AI)
- BYOK (direct API with your key)
- Backend (hosted API, no key needed)

### MCP Compatibility

Full Model Context Protocol support:
- SSE/HTTP transport for remote servers
- StdIO via backend proxy
- WebMCP for page-provided tools

### Human-in-the-Loop

Safety controls for AI actions:
- Read-only tools execute automatically
- Destructive tools require approval
- WebMCP tools always require consent
