Configure Cognito AI to match your preferences and workflow. Settings are organized across the extension and webapp.

## Configuration Areas

| Area | Location | What's Configured |
|------|----------|-------------------|
| **Quick Settings** | Extension side panel | Model, mode, basic toggles |
| **Full Settings** | Webapp (new tab) | All preferences, memory, MCP |
| **Environment** | `.env` file | Build-time configuration |
| **Permissions** | Chrome | Extension access levels |

## Quick Tour

### Extension Quick Settings

Access directly in the side panel:
- AI model selection
- Backend/BYOK mode toggle
- Tools mode selection
- Voice mode toggle

### Webapp Settings

Full configuration in a dedicated page:
- API key management
- Memory settings
- MCP server management
- Feature preferences

## Common Tasks

### Switch AI Modes

Open the side panel and click the mode selector. Choose:

- **Backend Mode** — No API key needed
- **BYOK Mode** — Use your own API key

### Configure MCP Servers

Navigate to **Settings** → **MCP Servers**, enable desired servers, and complete authentication when prompted.

### Manage Memory

Navigate to **Settings** → **Memory**, enter your Supermemory API key, and toggle auto-extraction as needed.
