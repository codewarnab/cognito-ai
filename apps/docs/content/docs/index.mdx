Welcome to the **Cognito AI** documentation.

Cognito AI is an [open-source](https://github.com/codewarnab/cognito-ai), privacy-first, AI-powered Chrome extension that helps you browse and research more effectively. Your API keys and other credentials never leave your device.

## Key Features

- **AI Side Panel** - Chat with AI while browsing
- **Browser Automation** - Automate browser tasks
- **MCP Integration** - Connect to external tool servers
- **Privacy-First** - Your data stays on your device
- **BYOK Mode** - Use your own API key
