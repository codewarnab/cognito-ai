---
title: Adding an MCP Server
description: A step-by-step guide to registering and configuring a new Model Context Protocol (MCP) server in the Cognito AI extension.
---

This guide details the process of integrating a new MCP server into the Cognito AI extension. The extension functions as an MCP Client, capable of connecting to various MCP Servers to extend its capabilities.

## Prerequisites

-   Access to the codebase.
-   The URL of the MCP server you wish to connect to (e.g., `https://api.example.com/mcp`).
-   An icon for the integration (optional but recommended).

## Step-by-Step Integration

### 1. Add the Integration Icon

If you have a brand icon for the MCP server, add it to the extension's assets.

1.  Place your icon file (e.g., `myserver.svg`, `myserver.png`, or `myserver.webp`) in:
    `apps/extension/assets/brands/integrations/`
2.  If using a React component for the icon (SVG), ensure it's properly exported. If using a raster image, you will import it directly.

### 2. Update Manifest Permissions

To allow the extension to connect to the external MCP server, you must declare the URL in the extension's manifest.

1.  Open `apps/extension/package.json`.
2.  Locate the `manifest.host_permissions` array.
3.  Add the URL pattern for your MCP server.

```json title="apps/extension/package.json"
"host_permissions": [
    "https://youtube-transcript-generator-five.vercel.app/*",
    "https://api.myserver.com/*", // Add your server URL here
    "<all_urls>"
],
```

> [!IMPORTANT]
> Without this permission, the browser will block the connection request to the MCP server.

### 3. Configure the Server Entry

The core configuration lives in `apps/extension/src/constants/mcpServers.tsx`.

1.  Open `apps/extension/src/constants/mcpServers.tsx`.
2.  Import your icon.

    ```tsx
    // For React Component icons
    import { MyServerIcon } from "@assets/brands/integrations/MyServerIcon"
    
    // OR for Image files
    import myServerImage from "@assets/brands/integrations/myserver.webp"
    ```

3.  Add a new entry to the `MCP_SERVERS` array.

```tsx title="apps/extension/src/constants/mcpServers.tsx"
export const MCP_SERVERS: ServerConfig[] = [
    // ... existing servers
    {
        id: "my-server-id", // Unique internal ID
        name: "My Server Name", // Display name
        icon: <MyServerIcon />, // OR <img src={myServerImage} alt="My Server" style={{ width: 24, height: 24 }} />
        initialEnabled: false,
        initialAuthenticated: false,
        url: "https://api.myserver.com/mcp", // The SSE endpoint
        description: "Description of what this server provides.",
        requiresAuthentication: true, // Set to true if OAuth is needed
        
        // Optional: Paid feature flag
        // paid: true,

        // Optional: OAuth Configuration (if discovery is not supported)
        // oauth: {
        //     scopes: ["read:user", "write:data"]
        // }
    },
];
```

### 4. Authentication (If Required)

If `requiresAuthentication` is set to `true`, the extension will attempt to perform an OAuth handshake using the server's discovery endpoint.

-   Ensure the MCP server supports Dynamic Client Registration (DCR) or has a static client configured for the extension.
-   If the server does not support DCR, you might need to manually configure client IDs (currently, the implementation relies heavily on discovery or pre-configured defaults).

## Verification

1.  **Rebuild/Reload the Extension**: Changes to `package.json` or `mcpServers.tsx` usually require a full extension reload.
    ```bash
    pnpm dev
    ```
2.  **Open the Side Panel**: Use `Ctrl+Shift+H` (or `Cmd+Shift+H`).
3.  **Navigate to MCP Settings**: Click the specialized tool/MCP icon (usually in the header or tools menu).
4.  **Find Your Server**: Verify your new server appears in the list with the correct name, icon, and description.
5.  **Connect**: Toggle the switch to enable/connect. Watch the `Service Worker` console for connection logs:
    -   `[MCP] Connecting to...`
    -   `[MCP] Connection established`

## Troubleshooting

-   **Connection Failed**: Check the browser console (Inspect Side Panel or Background Page). Look for CORS errors or network failures.
-   **Icon Missing**: Verify the import path in `mcpServers.tsx` matches the file location in `assets/brands/integrations`.
-   **Permissions Error**: Double-check `host_permissions` in `package.json` and ensure you reloaded the extension.
