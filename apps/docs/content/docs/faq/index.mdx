Answers to common questions about Cognito AI.

## General

<Accordions>
  <Accordion title="What is Cognito AI?" id="what-is-cognito">
    Cognito AI is a privacy-first, AI-powered Chrome extension that helps you browse and work more effectively. It provides an AI assistant in a side panel that can read pages, automate tasks, and connect to external tools via MCP.
  </Accordion>

  <Accordion title="Is Cognito AI free?" id="is-free">
    Yes. Cognito AI is open source and free to use. Some features require:
    - **AI API access**: Either use Cloud mode (free with rate limits) or provide your own Google AI API key (BYOK)
    - **Voice mode**: Requires ElevenLabs service configuration
    - **Memory features**: Requires Supermemory API key
  </Accordion>

  <Accordion title="What browsers are supported?" id="browsers-supported">
    Currently Cognito AI supports **Google Chrome version 120 or later**. It may work on Chromium-based browsers like Edge and Brave, but these are not officially supported.
  </Accordion>

  <Accordion title="What AI models are used?" id="ai-models">
    | Mode | Model |
    |------|-------|
    | **Cloud** | gemini-2.5-flash (fixed) |
    | **BYOK** | Any Gemini model you choose |
    | **Local** | Gemini Nano (Chrome built-in) |
  </Accordion>
</Accordions>

## Privacy

<Accordions>
  <Accordion title="Does Cognito AI collect my data?" id="data-collection">
    **No.** Cognito AI is local-first:
    - Conversations stored locally in IndexedDB
    - Settings stored in Chrome storage
    - No analytics or telemetry
    - No data sent to Cognito servers (except Cloud mode)

    See [Privacy Model](/docs/security/privacy-model) for details.
  </Accordion>

  <Accordion title="What happens to my API key in BYOK mode?" id="byok-api-key">
    Your API key **never leaves your device**. In BYOK mode, the extension makes direct API calls to Google AI. The key is stored in Chrome's encrypted storage and used only for those direct calls.
  </Accordion>

  <Accordion title="What data is sent to the AI?" id="data-sent-to-ai">
    Only data you explicitly interact with:
    - Your message text
    - Page content (when you ask about the page)
    - Selected text (when using Writer/Rewriter)

    **Never sent**: Passwords, credit card numbers, SSNs, or data from other tabs.
  </Accordion>

  <Accordion title="Is Cloud mode private?" id="cloud-mode-privacy">
    Cloud mode routes your messages through Cognito's Vercel backend, which then calls Google AI. Your data is:
    - Transmitted over TLS
    - Not stored on our servers
    - Not used for training

    For maximum privacy, use BYOK mode.
  </Accordion>
</Accordions>

## Features

<Accordions>
  <Accordion title="What can Cognito AI do?" id="features-overview">
    | Category | Features |
    |----------|----------|
    | **Chat** | AI conversations, page Q&A |
    | **Content** | Writing, rewriting, summarizing |
    | **Automation** | Browser tasks, form filling |
    | **Research** | Web search, page analysis |
    | **Voice** | Voice input and output |
    | **Memory** | Long-term context (with Supermemory) |
    | **MCP** | External tool integration |
  </Accordion>

  <Accordion title="Does voice mode work offline?" id="voice-offline">
    No. Voice mode requires a network connection to the ElevenLabs service. It proxies through Cognito's Cloudflare worker.
  </Accordion>

  <Accordion title="Can I use Cognito AI offline?" id="offline-usage">
    **Partially.** In Local mode (Chrome built-in AI), basic chat works offline. However, most features require network access:
    - BYOK/Cloud mode: Requires Google AI API
    - Voice mode: Requires ElevenLabs
    - MCP: Requires server connections
    - Web search: Requires Tavily API
  </Accordion>

  <Accordion title="How does browser automation work?" id="browser-automation">
    Cognito AI can perform browser actions through the AI:
    1. You describe what you want
    2. AI uses tools like `navigateTo`, `clickByText`, `typeInField`
    3. Sensitive actions require your approval
    4. AI executes the approved actions

    See [Browser Automation](/docs/using-cognito/browser-automation).
  </Accordion>
</Accordions>

## API Keys

<Accordions>
  <Accordion title="How do I get a Google AI API key?" id="get-api-key">
    1. Visit [Google AI Studio](https://aistudio.google.com/)
    2. Sign in with your Google account
    3. Create an API key
    4. Copy and paste into Cognito settings

    See [Provider Setup](/docs/getting-started/provider-setup) for details.
  </Accordion>

  <Accordion title="Is there a free tier?" id="free-tier">
    Yes. Google AI provides a free tier with generous limits for personal use. Check current limits at [Google AI pricing](https://ai.google.dev/pricing).
  </Accordion>

  <Accordion title="Can I use other AI providers?" id="other-providers">
    Currently, Cognito AI supports:
    - **Google AI** (Gemini family) — Full support
    - **Chrome built-in AI** (Gemini Nano) — Limited features

    Support for other providers may be added in the future.
  </Accordion>
</Accordions>

## MCP (Model Context Protocol)

<Accordions>
  <Accordion title="What is MCP?" id="what-is-mcp">
    MCP is an open standard for connecting AI to external tools. Cognito implements an MCP client that can connect to:
    - **Remote servers** (Notion, Linear, etc.)
    - **StdIO servers** (command-line tools via backend)
    - **WebMCP** (page-provided tools)

    See [MCP Overview](/docs/integrations/mcp-overview).
  </Accordion>

  <Accordion title="How do I connect an MCP server?" id="connect-mcp">
    1. Go to **Settings** → **MCP Servers**
    2. Enable the server you want
    3. Complete OAuth if required
    4. Server tools appear in your chat
  </Accordion>

  <Accordion title="Are MCP tools safe?" id="mcp-safety">
    MCP tools require approval:
    - **Remote MCP**: Configurable per-server
    - **WebMCP**: Always requires approval

    All tool executions show the tool name and arguments before running.
  </Accordion>
</Accordions>

## Troubleshooting

<Accordions>
  <Accordion title="The side panel won't open" id="side-panel-issue">
    **Solutions:**
    1. Try the keyboard shortcut: `Ctrl+Shift+H` (or `Cmd+Shift+H` on Mac)
    2. Click the Cognito icon in the extension toolbar
    3. Check that the extension is enabled in `chrome://extensions`
    4. Restart Chrome
  </Accordion>

  <Accordion title="I'm getting 'Rate limit exceeded'" id="rate-limit">
    **In Cloud mode**: The shared API has usage limits. Either:
    - Wait a few minutes
    - Switch to BYOK mode with your own key

    **In BYOK mode**: You've hit your Google AI API limits. Check your usage in Google AI Studio.
  </Accordion>

  <Accordion title="Tools aren't appearing" id="tools-not-appearing">
    **Check:**
    - Is the correct Tools mode selected? (Chat mode has minimal tools)
    - Is the MCP server connected?
    - Refresh the page for WebMCP tools
  </Accordion>

  <Accordion title="Voice mode doesn't work" id="voice-not-working">
    **Check:**
    - Is the ElevenLabs worker configured?
    - Does your browser have microphone permission?
    - Check the browser console for errors
  </Accordion>
</Accordions>
