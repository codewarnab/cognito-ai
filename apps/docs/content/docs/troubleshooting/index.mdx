## Quick Diagnostics

| Symptom | Likely Cause | Go To |
|---------|--------------|-------|
| Extension not in toolbar | Install issue | [Install](/docs/troubleshooting/install) |
| Side panel empty | Provider setup | [Provider Setup](/docs/getting-started/provider-setup) |
| AI not responding | API key or rate limit | [Extension](/docs/troubleshooting/extension) |
| MCP server won't connect | Auth or URL issue | [MCP](/docs/troubleshooting/mcp) |
| Voice not working | Microphone or backend | [Voice](/docs/troubleshooting/voice) |

## General Tips

1. **Check browser console** — `F12` → Console tab for errors
2. **Reload extension** — Go to `chrome://extensions` → click reload
3. **Clear data** — Extension Details → Clear data (resets settings)
4. **Update Chrome** — Ensure Chrome 120+ is installed
