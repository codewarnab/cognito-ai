## Overview

Cognito AI can search the web and extract content from URLs to answer questions and research topics.

<Callout type="info" title="API Search vs Browser Search">
  This web search feature uses **external APIs** (Tavily, Jina) for search results. This is different from the browser automation where the AI navigates to Google and opens links manually.
  
  **API Search benefits:**
  - Faster results without page navigation
  - More relevant and structured data
  - Access to recent information
  - Doesn't interfere with your current browsing
</Callout>

## Search Tools

| Tool | Provider | Description |
|------|----------|-------------|
| `webSearch` | Tavily | General web search |
| `retrieve` | Jina Reader | Extract content from URLs |
| `deepWebSearch` | Tavily | Multi-query parallel search with deduplication |

## Using Web Search

### Simple Search

Ask a question that requires current information:

```text title="Example prompt"
What's the latest news about TypeScript 5.4?
```

The AI uses `webSearch` to find relevant results.

### Research a Topic

For in-depth research:

```text title="Example prompt"
Research the pros and cons of using Deno vs Node.js in 2024
```

The AI may use multiple searches and `retrieve` to gather information.

### Extract URL Content

Share a URL and ask for a summary:

```text title="Example prompt"
Summarize the key points from https://example.com/article
```

The AI uses `retrieve` (Jina Reader) to extract content.

## How It Works

| Step | Action |
|------|--------|
| 1 | AI determines search is needed |
| 2 | Search query sent to Tavily API |
| 3 | Results returned with snippets |
| 4 | (Optional) Jina extracts full content |
| 5 | AI synthesizes answer |

<Callout>
Web search uses the **backend API**. No additional API keys required.
</Callout>

## Search vs Page Context

| Feature | When to Use |
|---------|-------------|
| **Page context** | Asking about the current webpage |
| **Web search** | Finding external information |
| **URL retrieve** | Deep-diving into a specific URL |

## Prompting Tips

<Callout type="warn" title="Web Search Not Triggering?">
  If the AI isn't using web search when you expect it to, try being explicit in your prompt:
  
  > "Use web search to find recent information about [topic]"
  
  > "Search the web for the latest updates on [topic]"
  
  This helps the AI understand you want external search results rather than relying on its training data.
</Callout>

## Limitations

- **Rate limits** — Backend has usage quotas
- **Recency** — Search index may have slight delays
- **Paywalls** — Cannot access gated content
