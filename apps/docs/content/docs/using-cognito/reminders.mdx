## Overview

Cognito AI can set reminders that trigger Chrome notifications at specified times. Ask naturally to create reminders, then manage them from the webapp.

## Create a Reminder

Use natural language in the chat to create reminders:

```text title="Examples"
Remind me to check emails in 30 minutes
Set a reminder for 3pm to join the standup
Remind me tomorrow at 9am to review the PR
```

### Reminder Tools

| Tool | Description |
|------|-------------|
| `createReminder` | Schedule a new reminder |
| `listReminders` | View active reminders |
| `cancelReminder` | Delete a reminder |

## How It Works

| Step | Action |
|------|--------|
| 1 | AI parses your reminder request |
| 2 | `createReminder` tool schedules via Chrome Alarms API |
| 3 | Alarm triggers at specified time |
| 4 | Chrome notification appears |

## Managing Reminders

### Via Chat

Ask Cognito to list or cancel reminders:

```text title="Examples"
What reminders do I have?
Cancel my 3pm reminder
```

### Webapp Interface

The [Reminders page](/reminders) provides full reminder management:

- **View** all scheduled reminders
- **Edit** reminder title, time, and description
- **Delete** individual reminders
- **Pause/resume** reminders

<Callout>
  Open the reminders page from the extension's **three-dot menu** or navigate directly to `/reminders` in the webapp.
</Callout>

## Notifications

Reminders trigger Chrome browser notifications:

| Setting | Location |
|---------|----------|
| **Sound** | Settings → Enable Notification Sound |
| **Chrome notifications** | Chrome OS/system settings |

<Callout type="warn">
  Ensure Chrome notifications are enabled in your system settings for reminders to appear.
</Callout>

## Limitations

| Limitation | Details |
|------------|---------|
| **Browser must be open** | Chrome needs to be running |
| **Extension active** | Extension must not be disabled |
| **Time zones** | Uses your local system time |
