## Overview

Voice mode allows spoken interaction with Cognito AI. Speak your questions and hear responses through ElevenLabs text-to-speech.

<Callout type="warn" title="Experimental Feature">
  Voice Mode is an **experimental feature** behind a feature flag and may not be available to all users. The feature is still under active development.
</Callout>

<Callout type="error" title="Known Issue: Double Execution">
  Voice Mode currently has a **double execution problem** where commands may be executed twice. We are actively working on a fix. Use with caution for actions that shouldn't be repeated.
</Callout>

<Callout title="Backend Required">
  Voice mode uses the ElevenLabs integration via a backend proxy.
</Callout>

<Callout type="warn" title="Building from Source">
  If you are building the extension from source (not using the store version), Voice Mode might not work out of the box because it requires backend authentication. 
  
  Please refer to the [Installation Guide](/docs/getting-started/installation) to set up your own backend or configure the necessary environment variables.
</Callout>

## Prerequisites

- Cognito AI installed and configured
- Microphone access granted to Chrome
- Speakers or headphones

## Enable Voice Mode

1. Open the side panel (`Ctrl+Shift+H`)
2. Open **Settings**
3. Toggle **Enable Voice Mode** on

## Using Voice Mode

### Start a Voice Conversation

1. Click the **microphone** button in the input area
2. Allow microphone access if prompted
3. Speak your message
4. Wait for the AI response (played as audio)

### End Voice Mode

Click the microphone button again or press **Escape**.

## Technical Details

The voice architecture ensures security and low latency:

<ImageZoom src="/voice-architecture.png" alt="Voice Architecture Diagram" width={800} height={400} />

| Component | Technology |
|-----------|------------|
| **Voice synthesis** | ElevenLabs API |
| **Backend proxy** | Cloudflare Worker |
| **Audio processing** | Web Audio API worklets |

The backend proxy handles API authentication so you don't need an ElevenLabs API key.

## Limitations

- **Language** — Best support for English
- **Background noise** — Quiet environment recommended
- **Response time** — Slight delay for synthesis
- **Availability** — Requires backend connectivity
