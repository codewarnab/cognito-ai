## What You'll Learn

- Navigating the side panel interface
- Managing chat threads
- Using attachments
- Keyboard shortcuts

## Open the Side Panel

| Platform | Shortcut |
|----------|----------|
| **Windows/Linux** | `Ctrl+Shift+H` |
| **Mac** | `Cmd+Shift+H` |

Or click the Cognito AI icon in your Chrome toolbar.

## Interface Components

### Chat Area

The main area displays your conversation with the AI. Messages appear in order with:
- **Your messages** on the right
- **AI responses** on the left
- **Tool results** inline with collapsible details

### Input Area

The bottom input area includes:
- **Message field** — Type your message
- **Attachment button** — Add screenshots or files
- **Send button** — Submit your message

### Settings & Navigation

Access settings and other features via the toolbar icons:
- **Settings gear** — Configure provider, modes, preferences
- **New thread** — Start a fresh conversation
- **Thread history** — View past conversations

## Managing Threads

### Create a New Thread

Click the **+** button or use the menu to start a new conversation. Previous threads are saved automatically.

### Switch Between Threads

Open the thread list from the sidebar to view and switch between conversations.

### Delete a Thread

From the thread list, hover over a thread and click the delete icon.

## Attachments

Attach context to your messages:

| Attachment Type | How to Add |
|-----------------|------------|
| **Screenshot** | Click attachment icon → Screenshot |
| **Current page** | Automatically included when asking about the page |
| **Files** | Drag and drop or click to upload |

> [!TIP]
> Include a screenshot when asking about visual elements on a page.

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+Shift+H` | Toggle side panel |
| `Enter` | Send message |
| `Shift+Enter` | New line in message |
| `Escape` | Close modals/menus |
