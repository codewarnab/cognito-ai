## Overview

Cognito AI uses [Supermemory](https://supermemory.ai) for persistent, cloud-based memory. Unlike traditional local storage, Supermemory builds a **semantic knowledge graph** that evolves as you interact with the AI.

<ImageZoom src="/super-memory-architecture.png" alt="Supermemory Architecture" width={800} height={500} />

<Callout>
  Supermemory stores memories in the cloud, not on your device. Your API key controls access to your personal memory store.
</Callout>

## How It Works

### Memory Storage

| Aspect | Description |
|--------|-------------|
| **Storage location** | Supermemory cloud servers |
| **Access control** | Your personal API key |
| **User isolation** | Unique user ID per extension |
| **Indexing** | Semantic understanding graph |

Supermemory extracts **facts** from your interactions—preferences, topics you research, writing styles—and organizes them into a queryable knowledge base.

### Memory Retrieval

When you chat or use content features, Cognito searches your memories for relevant context:

| Feature | How Memories Help |
|---------|-------------------|
| **Chat** | AI recalls past conversations and preferences |
| **Writer** | Matches your established writing style |
| **Rewriter** | Applies consistent tone preferences |
| **Summarizer** | Connects to previously researched topics |

## Setup

### Get Your API Key

1. Visit [Supermemory Console](https://console.supermemory.ai)
2. Create an account or sign in
3. Generate an API key

### Configure in Cognito

1. Open the side panel (`Ctrl+Shift+H`)
2. Open **Settings** → **Advanced**
3. Expand **Supermemory** section
4. Paste your API key
5. Toggle **Enable Supermemory** on

<Callout type="warn">
  Your API key is stored locally in Chrome and only used to authenticate with Supermemory. It never passes through Cognito's servers.
</Callout>

## Automatic Memory Extraction

When enabled, Cognito automatically extracts memories from your interactions.

<Callout>
  This feature is currently behind a feature flag and may not be visible in all builds.
</Callout>

### Extraction Sources

| Source | What Gets Extracted |
|--------|---------------------|
| **Chat conversations** | Topics discussed, preferences stated, facts shared |
| **Summarizer** | Research interests, frequently visited topics |
| **Writer** | Writing topics, tone preferences, context patterns |
| **Rewriter** | Style preferences, common transformations |

### Trigger Conditions

Extraction runs when:

| Condition | Threshold |
|-----------|-----------|
| **Minimum messages** | 4+ messages in conversation |
| **Re-extraction** | 10+ new messages since last extraction |
| **Trigger event** | User switches threads or creates new chat |

### Enable Auto-Extraction

1. Open **Settings** → **Advanced**
2. Expand **Supermemory** section
3. Toggle **Auto-Extract Insights** on

## Memory Search

Cognito provides AI tools for memory interaction:

| Tool | Purpose |
|------|---------|
| `searchMemories` | Semantic search across your memory store |
| `addMemory` | Manually save important information |

These tools allow the AI to:
- Find relevant past context during conversations
- Store new facts you explicitly want remembered
- Provide personalized responses based on your history

## Managing Your Memories

### View Memories

Visit the [Supermemory Console](https://console.supermemory.ai) to:
- Browse stored memories
- Search your knowledge graph
- Delete specific memories

### Clear All Memories

From Supermemory Console:
1. Navigate to your memory store
2. Select memories to delete
3. Confirm deletion

<Callout type="warn">
  Deleting memories from Supermemory is permanent. The extension cannot recover deleted memories.
</Callout>

### Disable Memory Features

To stop memory collection:
1. Open **Settings** → **Advanced**
2. Toggle **Enable Supermemory** off

This stops new memories from being added but preserves existing data in Supermemory.

## Privacy Considerations

| Aspect | Detail |
|--------|--------|
| **Data ownership** | You control your Supermemory account |
| **API key security** | Stored locally, never sent to Cognito servers |
| **Memory deletion** | Full control via Supermemory Console |
| **Feature toggle** | Disable anytime without data loss |

For Supermemory's privacy policy, see [Supermemory Documentation](https://supermemory.ai/docs/introduction).
