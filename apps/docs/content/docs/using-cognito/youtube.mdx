## Overview

Cognito AI can analyze YouTube videos by fetching and processing their transcripts. Ask questions about video content, get summaries, or extract key points.

## Using YouTube Analysis

### Summarize a Video

Navigate to a YouTube video and ask:

```text title="Example prompt"
Summarize this video
```

Or provide a URL:

```text title="Example prompt"
What are the main points in https://youtube.com/watch?v=...
```

### Ask Specific Questions

```text title="Example prompt"
What does the speaker say about machine learning?
```

```text title="Example prompt"
Give me timestamps for when they discuss pricing
```

### Extract Information

```text title="Example prompt"
List all the tools mentioned in this video
```

## How It Works

| Step | Action |
|------|--------|
| 1 | AI detects YouTube video context |
| 2 | `getYouTubeTranscript` tool fetches transcript |
| 3 | Transcript returned with timestamps |
| 4 | AI processes and responds |

<Callout>
Transcripts are fetched through the **backend API**. No additional setup required.
</Callout>

## Requirements

| Requirement | Details |
|-------------|---------|
| **Captions** | Video must have captions enabled |
| **Public access** | Works on public videos |
| **Language** | Best results with English captions |

## Limitations

- **No captions** — Some videos lack transcripts
- **Auto-generated** — May have accuracy issues
- **Private videos** — Cannot access private content
- **Live streams** — Limited support for live content

## Video Metadata

The tool also returns video metadata:

| Field | Description |
|-------|-------------|
| `title` | Video title |
| `channelName` | Channel name |
| `duration` | Video length |
| `viewCount` | View count |

## Best Practices

1. **Be specific** — "What does X say about Y at the beginning?"
2. **Check captions** — Verify the video has subtitles
3. **Use timestamps** — Ask for time references
