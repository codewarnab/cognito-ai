## Feature Overview

| Feature | Description |
|---------|-------------|
| **Side Panel** | Chat interface, threads, attachments |
| **Browser Automation** | Navigate, click, type, extract data |
| **Voice Mode** | Speak instead of typing (ElevenLabs) |
| **Memory** | Local storage for preferences and context |
| **Web Search** | Research topics via Tavily/Jina |
| **YouTube** | Analyze videos via transcripts |
| **Web MCP** | Integration with web-based MCP servers |
| **Remote MCP** | Connect to 20+ remote MCP servers |
| **Custom MCP** | Add your own remote MCP server URLs |
| **Reminders** | Set and manage reminders |

## Adding Custom Remote MCP Servers

In addition to the pre-configured MCP servers, you can add your own remote MCP server URLs:

1. Open the side panel (`Ctrl+Shift+H`)
2. Open **Settings** → **MCP Servers**
3. Click **Add Custom Server**
4. Enter the server URL and name
5. The server's tools will appear in the Tools popover

<Callout>
  Custom MCP servers follow the same approval system as built-in tools. All MCP tool calls require user approval before execution.
</Callout>
